# Plugins VST3

Los plugins `.vst3` que pongas aquí se copian en `C:\Program Files\Common Files\VST3\`, donde los encuentra atkAudio dentro de OBS. El script instala atkAudio en las mesas.

Un `.vst3` puede ser un archivo o una carpeta. Copia el elemento completo tal como está en `C:\Program Files\Common Files\VST3\` de una mesa ya configurada.
