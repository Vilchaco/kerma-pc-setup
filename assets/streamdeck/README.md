# Stream Deck

Un perfil por juego, exportado desde la app de Stream Deck: en la lista de perfiles, menú del perfil, **Exportar**.

| Archivo | Mesas |
|---|---|
| `roulette.streamDeckProfile` | Roulette |
| `blackjack.streamDeckProfile` | Blackjack 01 a 04 |
| `blackjack-unlimited.streamDeckProfile` | Blackjack Unlimited |
| `craps.streamDeckProfile` | Craps |

El script abre el perfil con la app de Stream Deck. Si la app pregunta si quieres importarlo, acepta.
