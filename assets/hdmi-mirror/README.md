# HDMI Mirror

Copia aquí el archivo `hdmimirror.config.json` de una mesa ya ajustada. Está junto a `HdmiMirror.exe`.

Renómbralo con la clave de la mesa de la tabla de PCs del script:

| Archivo | Mesa |
|---|---|
| `RL01.json` | Roulette 01 |
| `BJ01.json` a `BJ04.json` | Blackjack 01 a 04 |
| `BJUNL01.json` | Blackjack Unlimited 01 |
| `CR01.json` | Craps 01 |
| `default.json` | Cualquier mesa sin archivo propio |

Si la mesa ya tiene una configuración, el script pregunta antes de reemplazarla y guarda una copia de la anterior.
